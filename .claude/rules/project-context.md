## Test data

- `.variations/CoverWellEnrollmentData.json` (3 rows: Silver/2 people, Gold/1 person, Bronze/high income $0 savings), bound via `dataVariationFilePath` in project.json. Test case arguments match the JSON fields (all strings, named `in_*` per the org's argument-naming rule, e.g. `in_ZipCode`, `in_PlanName`); defaults = row 1.
- `uip rpa test-data add-variation` fails with this Studio version ("Studio does not support rpa-tool"); arguments/defaults were added by hand.
- Local runs use row 1; run other rows with `uip rpa debug start ... --input-arguments-file <row.json>`.
- Plan names are generated by the site: `{carrier} {tier} {Value|Plus|Select|Choice}`, see `buildPlans()` in `TestSite/index.html`.

## System under test: CoverWell demo site (`TestSite/`)

- `TestSite/data/enrollments.db` is listed in project.json `processOptions.ignoredFiles` (kept out of the package).
- `TestSite/server.py` — Python stdlib server + SQLite (`TestSite/data/enrollments.db`), binds 127.0.0.1. Start: `python TestSite\server.py` (port 8080). Must be running before the test.
- API: `POST/GET/DELETE /api/enrollments`, `GET/DELETE /api/enrollments/{confirmation}`, filters `?email=&last_name=&confirmation=`.
- `TestSite/index.html` — single-page site; all views share one URL, so one Object Repository screen covers every step. `TestSite/admin.html` — record viewer.

## Conventions / gotchas

- Use Browser card: `OpenMode=Always`, `CloseMode=Always`, `WindowResize=Maximize` — a background (unpainted) Edge window makes DebuggerApi typing time out.
- Date of birth is a native `<input type="date">`: type `mm/dd/yyyy`, `EmptyFieldMode=None`, no TypeInto auto-verify (the value is ISO so verification never matches).
- `VerifyExpressionWithOperator` operands must use element form (`InArgument x:Object` + `VisualBasicValue x:Object`), not `FirstExpression="[...]"`.
